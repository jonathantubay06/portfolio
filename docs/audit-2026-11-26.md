# Portfolio audit, 2026-11-26

Owner: Jojo (personal). Site: https://jonathantubay.com (live commit 8e59a5e at audit time).

## How it was checked

- Live site: response headers, every page, exposed-path probes, the /api/ask chat, GitHub CI runs, Dependabot alerts.
- Local build on 9 device profiles with Playwright (iPhone SE, iPhone 15 Pro Max, iPad mini, iPad Pro in WebKit; Pixel 7, Galaxy S9+, Galaxy Tab S4, 1366 laptop, 1920 desktop in Chromium): load, full scroll, sideways overflow, broken images, dead anchors, duplicate ids, tap-target sizes, idle frame activity, CSS and JS coverage, and these interactions: nav drawer, theme toggle, video modal, project modal, FAQ, Ask my AI, empty contact-form submit.
- Desktop 3D world with real WebGL (RX 9060 XT through ANGLE): errors, context state, frame activity.
- Lighthouse 12.6 against the live site, phone and desktop.
- Code read by two read-only helpers (unused files, risk spots), findings judged by hand.

## Results

| Area | Result |
|---|---|
| Functions | Every interaction passed on all 9 devices. No page errors. |
| Layout | No sideways scroll, no broken images, no dead anchors, no duplicate ids. |
| Security | CSP with hashed inline scripts, HSTS preload, COOP, X-Frame-Options DENY, nosniff, Permissions-Policy. Source, history, docs, function code and config all return 404. 0 open Dependabot alerts. Chat blocks other origins and never returns upstream errors or the key. |
| Reliability | CI green on the last push. security.txt valid to 2027-10-24 and renews on each deploy. |
| Lighthouse phone | Performance 89, Accessibility 100, Best practices 100, SEO 100. LCP 3.1 s (simulated slow 4G), TBT 50 ms, CLS 0.04. |
| Lighthouse desktop | Performance 52, Accessibility 100, Best practices 100, SEO 100. LCP 1.8 s, TBT 1,240 ms, CLS 0.02. The low score is the 3D world starting up on a lab machine with no GPU; on a real GPU the world ran with no errors. |
| Phones idle | 0 animation frames per second when nothing moves. |

## Fixed in this pass (local until pushed)

1. Theme setup no longer stops when the browser blocks storage (inline head script and the toggle).
2. Back to top respects reduced motion.
3. Contact form gives up after 15 s on a dead connection and shows the email fallback.
4. Chat function logs the upstream status code (never the body or the key) and trims its rate-limit table.
5. "Read full review" and the timeline "More" pill get a 44 px tall tap area.
6. Chat knowledge now includes the Notes page; llms.txt lists Now, Uses and Notes.
7. CI pinned to ubuntu-24.04 (ubuntu-latest moved to 26.04, which broke headless Chrome in two other repos).
8. Removed unused code: 3 script files never loaded (text scramble, magnetic buttons, HUD cursor) and about 10 KB of CSS that only they used (HUD cursor, magnetic and press states, the dropped booking pill).
